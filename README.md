# Merhaba, Ben Sıla! 👋

Yönetim Bilişim Sistemleri (YBS) öğrencisiyim. Veri bilimi, makine öğrenmesi ve yazılım geliştirme süreçlerine ilgi duyuyor; karmaşık verilerden anlamlı iş içgörüleri çıkarmaya ve süreçleri otomatize etmeye odaklanıyorum.

### 🔍 İlgi Alanlarım
- 📊 **Veri Bilimi ve Analizi:** Python ile uçtan uca makine öğrenmesi modelleri geliştirme ve istatistiksel analiz.
- 💻 **Yazılım Geliştirme:** C# ve SQL Server tabanlı kurumsal otomasyon ve veritabanı yönetimi.
- 📈 **Karar Destek Sistemleri:** Veri ön işleme, model optimizasyonu ve performans metrikleri (ROC, Confusion Matrix, R²).

### 🛠️ Yetkinliklerim
- **Programlama Dilleri:** Python, C#, SQL, Html
- **Veri Bilimi:** Pandas, Scikit-Learn, NumPy, Matplotlib, Seaborn
- **Araçlar & Teknolojiler:** Jupyter Notebook, SQL Server Management Studio (SSMS), Git & GitHub
